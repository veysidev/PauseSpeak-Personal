# PauseSpeak 1.1.19 — alt kenara uyarlanan altyazılar

Bu sürüm yalnızca istemci arayüzünün tam ekran yerleşimini değiştirir; yeni bir API çağrısı eklemez.

## Kontroller gizliyken

- Altyazı kartının alt konumu ekran yüksekliğine göre `16–40 px` arasında ölçeklenir.
- Güvenli ekran alanı alt boşluğa eklenir.
- Eylem düğmesi satırı yerleşimden çıkarılır; yalnız İngilizce ve Türkçe altyazılar kalır.

## Kontroller görünürken

- Altyazı kartı oynatıcı kontrollerinin üzerindeki normal konumunu kullanır.
